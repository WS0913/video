🔍 摄像头心跳机制详解

💡 什么是心跳机制？

心跳机制就像设备和服务器之间的"定期打卡"。摄像头每隔一段时间就向服务器发送一个信号，告诉服务器： "我还活着！"。如果服务器长时间收不到这个信号，就会认为设备离线了。

📡

客户端主动上报

摄像头主动发送心跳请求

🖥️

服务端被动接收

服务器记录心跳时间

⏰

定时检测超时

服务端检查设备是否在线

🔄 心跳工作流程

1️⃣ 设备注册
→
2️⃣ 获取设备ID
→
3️⃣ 启动心跳线程
→
4️⃣ 定时发送心跳
→
5️⃣ 服务端更新状态

第一步：设备注册

摄像头启动后，首先向服务器注册自己，获取唯一的设备ID

第二步：启动心跳线程

注册成功后，开启一个独立的"心跳线程"，专门负责发送心跳

第三步：定时发送心跳

每隔10秒，心跳线程向服务器发送一次心跳请求

第四步：服务端更新状态

服务器收到心跳后，更新设备的"最后心跳时间"，标记设备为在线

📱 客户端代码实现

1. 心跳线程启动

def start_heartbeat(self, interval=10):
    # 检查设备是否已注册
    if self.device_id is None:
        print("设备未注册，无法启动心跳")
        return
    
    self.running = True
    # 创建守护线程，专门处理心跳
    self.heartbeat_thread = threading.Thread(
        target=self._heartbeat_loop,
        args=(interval,),
        daemon=True  # 主线程退出时自动结束
    )
    self.heartbeat_thread.start()
    print(f"❤️ 心跳已启动，间隔: {interval}秒")

2. 心跳循环核心

def _heartbeat_loop(self, interval):
    while self.running:
        try:
            # 向服务器发送心跳请求
            response = requests.post(
                f'{self.server_url}/api/devices/{self.device_id}/heartbeat',
                json={'timestamp': time.time()},
                timeout=5  # 5秒超时，防止卡死
            )
            
            if response.status_code == 200:
                print(f"✅ 心跳成功: {self.device_id}")
            else:
                print(f"❌ 心跳失败: {response.status_code}")
                
        except Exception as e:
            print(f"⚠️ 心跳异常: {e}")
        
        # 等待指定间隔后再次发送
        time.sleep(interval)

💡 关键知识点：使用守护线程可以确保主程序退出时，心跳线程也会自动结束，不会变成僵尸进程。

🖥️ 服务端代码实现

1. 接收心跳请求

@router.post("/{device_id}/heartbeat")
async def device_heartbeat(device_id: str, db: AsyncSession):
    # 更新数据库中的心跳时间和状态
    stmt = update(Device).where(
        Device.device_id == device_id
    ).values(
        last_heartbeat=datetime.utcnow(),  # 记录当前时间
        status="online"                     # 标记为在线
    )
    
    result = await db.execute(stmt)
    await db.commit()
    
    return {"message": "心跳成功"}

2. 离线检测机制

async def check_device_status(self):
    # 计算超时时间点（当前时间 - 30秒）
    threshold_time = datetime.utcnow() - timedelta(seconds=30)
    
    # 查找所有在线但心跳超时的设备
    stmt = select(Device).where(
        Device.status == "online",
        Device.last_heartbeat < threshold_time
    )
    
    result = await db.execute(stmt)
    timeout_devices = result.scalars().all()
    
    # 将超时设备标记为离线
    for device in timeout_devices:
        print(f"⏰ 设备超时离线: {device.device_id}")
        device.status = "offline"
    
    await db.commit()
